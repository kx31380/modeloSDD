# Constitución del Proyecto

1. **Lenguaje:** Usaremos JavaScript básico (Node.js).
2. **Calidad:** El código debe ser lo más simple posible, sin librerías externas innecesarias.
3. **Pruebas:** Cada funcionalidad debe tener al menos un test que verifique que funciona y otro que verifique cómo maneja los errores.
4. **Soberanía Humana:** La IA no puede escribir código en `src/` hasta que el archivo `PLAN.md` esté marcado como aprobado por el humano.
