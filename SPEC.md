# Especificación: Calculadora de Sumas

## Objetivo
Queremos una función que reciba dos valores y devuelva el resultado de sumarlos.

## Requisitos funcionales
- Si se le pasa `2` y `3`, debe devolver `5`.
- Si uno de los dos valores no es un número (por ejemplo, es un texto como `"hola"`), el programa debe fallar y lanzar un error que diga: `"Ambos argumentos deben ser números"`.
